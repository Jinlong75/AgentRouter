# 任务说明

主导把能写清楚要求的工作写成任务说明，派给执行者：`ar dispatch docs/specs/NNN-简述.md --role worker`。

## 命名

`NNN-简述.md`，三位编号递增，例如 `001-登录页记住我.md`。

## 每份任务说明包含

1. **目标**：做完后是什么样子（一两句话）。
2. **背景与参照**：相关文件、已有实现、界面稿。
3. **要求**：逐条可检查的要求；不确定的地方写明"留 TODO(lead)"。
4. **允许改动的文件**：路径或通配符。
5. **验收**：要运行的命令（如 `npm test`）和要看的结果。
6. **汇报**：按 `docs/roles/worker.md` 的汇报格式。
